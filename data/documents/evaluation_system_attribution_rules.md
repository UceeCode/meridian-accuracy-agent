# Internal Evaluation System - Attribution Rules (v1.3)

1. Every task flagged by a reviewer is attributed to the employee assigned to it.
2. Exception: if a FAILED event from a processing job exists on the transaction date, the error is attributed to SYSTEM.
3. WARNING events, procedure versions, and task-record contents are not consulted.
4. Tasks with no supporting records are attributed to the assigned employee.

*Maintained by Finance Operations. Last reviewed: 2025-11.*
